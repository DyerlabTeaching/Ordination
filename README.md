## Impetus

Methods for dimensional reductions.

## Module Learning Objectives

### Perform and Interpret Principal Component Analysis

> Learners will perform a principal component analysis on multivariate data and describe how PC rotations work and what the resulting axes represent.

- **Bloom's Levels:** Apply, Understand
- **Reinforces:** Provides the first dimensional-reduction technique in the course, applied to multivariate genotype data.
- **Notes:** Interpreting *what an axis means* is emphasized as much as running the analysis itself.

### Conduct and Interpret Hierarchical Clustering

> Learners will conduct a hierarchical clustering analysis and interpret the resulting groupings in the context of the underlying data.

- **Bloom's Levels:** Apply, Analyze
- **Reinforces:** Offers a second, complementary dimensional-reduction/grouping approach alongside PCA, both applied to the same multivariate genotype data set.
- **Notes:** Clustering results are treated as hypotheses about structure in the data, to be interpreted rather than taken at face value.
